👤 Watumiaji wa Shule

☁️ Cloud Sync (Firebase)

⚪ Inaunganisha...

Data inahifadhiwa kwenye cloud na inapatikana kwenye vifaa vyote. Bila mtandao, data inabaki kwenye kifaa na inasync ukirudi mtandaoni. Usanidi wa Firebase uko kwenye code (config za web si siri kwa design — usalama unatoka kwenye Firestore rules na Firebase Auth).

💾 Data Management

Import ya backup inaonyesha preview kwanzi: utaona nini kitaongezwa na nini kubadilishwa kabla ya kuthibitisha. Kitufe cha "Data ya Kale" kinachukua wanafunzi waliohifadhiwa kwenye browser hii na toleo la zamani la mfumo.
